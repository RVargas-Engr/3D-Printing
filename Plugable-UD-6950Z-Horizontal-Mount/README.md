# Overview
This folder contains an .STL file and a .3MF file for a 3D model of a shell that can house a Plugable UD-6950Z Docking Station to allow it to be oriented horizontally on a tabletop.
This shell might also be compatible with other similar models from Plugable.

The files are also available at www.thingiverse.com.
